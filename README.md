# Habit Plus

A lightweight, responsive habit tracker focused on consistency. No build step or dependencies required.

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static web server.

## Features
- Daily habit checklist with custom habits, categories, and emoji
- Daily completion progress and weekly activity view
- XP points, levels, streak counter, and milestone card
- Responsive dark dashboard
- Local persistence with browser `localStorage`

## Notes
This is a front-end starter. Data is stored in the current browser only; authentication and cloud sync are not included yet.
